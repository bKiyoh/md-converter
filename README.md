<h1 align="center">Md Converter</h1>

Markdownで書いた文章を、SlackやBacklogへ貼り付けやすい形式に変換できるWebアプリです。

インストールやユーザー登録は必要ありません。

👉[Md Converterを開く](https://md-converter-10t.pages.dev/)


## どんなアプリ？

Markdownで文章を書きながら、Slack、Backlog、プレーンテキスト向けの変換結果をリアルタイムで確認・コピーできます。

入力した文章や設定はブラウザ内に保存され、外部サーバーへ送信されません。

## こんなことができます

- Slack向けの書式に変換
- Backlog Markdownへ変換
- Backlog記法へ変換
- 装飾を除いたプレーンテキストへ変換
- 変換結果をワンクリックでコピー
- 変換によって表現が変わる場合に警告を表示
- Markdownのプレビュー
- 複数の文章をタブで管理
- 文章の検索・置換
- よく使う文字列の入力置換
- 全角Markdown記号の入力補正
- ライトモード・ダークモード
- PC・スマートフォンの両方で利用

## 対応しているMarkdown

見出し、太字、斜体、打ち消し線、リスト、チェックリスト、引用、コード、リンク、テーブル、水平線、改行などに対応しています。

## 入力データについて

入力内容と設定は、利用しているブラウザのLocalStorageへ保存します。

- 入力内容を外部サーバーへ送信しません
- ログインやユーザー登録はありません
- ブラウザのサイトデータを削除すると、保存内容も削除されます
