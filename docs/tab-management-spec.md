# Markdownタブ管理・データ保存仕様

## 目的と対象範囲

複数のMarkdown文書を同じ画面で切り替えて編集し、タブ状態をブラウザ内へ保存する。バックエンド、ユーザー登録、外部API、クラウド同期、独自の編集履歴は実装しない。

## タブ

- 文書タブはMarkdown入力エリアの最上部へ配置し、ブラウザのタブを模した外観とする。
- アクティブなタブは入力面と連続して見えるようにし、入力エリア内へ `Input` と `Markdown入力` の説明見出しは表示しない。
- 初期状態は空の「Untitled」1件とする。
- 「＋」は現在の末尾タブの直後へ表示する。追加後は新しく作成した末尾タブの横へ移動する。
- 「＋」で追加し、現在のタブは最大7件とする。7件時は追加ボタンを無効化し、`タブは最大7つまで作成できます` をツールチップに表示する。
- 新規名称は、デフォルト名に使われていない最小の正整数を用い、1件目を `Untitled`、2件目以降を `Untitled N` とする。同名への変更は許可する。
- 各タブは一意のID、名称、Markdown入力、作成日時、更新日時を保持する。
- タブ切り替え時はMarkdown入力、Markdownプレビュー、変換結果、警告、コピー対象を選択中タブへ切り替える。変換形式とアプリ設定は全タブ共通とする。

## 名前変更

- タブのダブルクリックで編集を開始する。名称変更用のメニューボタンは表示しない。
- 前後の空白を削除した1〜30文字だけを確定できる。文字数はUnicodeコードポイントで数える。
- Enterまたはフォーカス離脱で確定し、Escapeで変更前の名称へ戻す。同名を許可する。

## 削除と復元

- 最後の1件は削除できない。削除確認ダイアログは表示しない。
- 各タブの右端に「×」アイコンの削除ボタンを表示し、押下時はメニューを介さず削除する。最後の1件ではボタンを無効化する。
- 内容が完全な空文字で、現在名がデフォルト形式の `Untitled` または `Untitled N`（Nは2以上）に一致するタブは、削除済み一覧へ保持せず即時に完全削除する。変更前に保存された `文章N` も同じ扱いを維持する。
- 空白文字を含む入力、内容があるタブ、または名前変更済みの空タブは通常どおり削除済み一覧へ保持する。既存データには名称変更履歴がないため、デフォルト名かどうかは現在名のデフォルト形式で判定する。
- 選択中タブを削除した場合は、削除位置に残った右隣を優先し、なければ左隣を選択する。
- 削除済みタブには削除日時と削除前の位置を加え、30日間保持する。
- タブ削除時は成功トーストや「元に戻す」を表示しない。復元は削除済み一覧から行い、可能な限り元の位置へ挿入する。
- 現在のタブが7件の場合は復元せず、`タブは最大7つまでです。\n復元するには、現在のタブを1つ削除してください。` を表示する。
- 完全削除したデータと、起動時点で削除後30日以上経過したデータは復元できない。
- 削除済みタブ一覧はゴミ箱アイコンと件数バッジから開く。各項目の復元は反時計回り矢印、完全削除は「×」付きゴミ箱のアイコンボタンとする。
- 削除済みタブ一覧を開いている間に一覧外をクリックした場合は、一覧を閉じる。一覧内またはゴミ箱アイコンのクリックでは外側クリックとして扱わない。
- アイコンボタンには操作対象を含む `aria-label` とツールチップを設定し、完全削除は危険操作として赤系のhover表示にする。

## 保存

```ts
type EditorTab = {
  id: string
  name: string
  content: string
  createdAt: number
  updatedAt: number
}

type DeletedTab = EditorTab & {
  deletedAt: number
  previousIndex: number
}

type EditorState = {
  version: 1
  tabs: EditorTab[]
  activeTabId: string
  deletedTabs: DeletedTab[]
}
```

- `localStorage` の `markdown-editor-state-v1` へJSONで保存する。
- 入力内容は最後の変更から500ミリ秒後、タブ操作は直後に保存する。
- 既存キー `md-converter:draft:v1` だけが存在する場合は、その内容を「Untitled」へ移行する。新形式の保存に成功した後で旧キーを削除する。
- JSON、バージョン、配列、1〜7件のタブ、必須項目、一意のID、名称、日時、選択中IDを検証する。破損時は警告をコンソールへ出し、初期状態へ戻す。
- LocalStorageの読み書きに失敗しても、画面上の編集と変換を継続する。

## 対象外と制約

- 独自のUndo/Redo履歴、複数ウィンドウ間の同期と競合解決、端末間同期、バックアップ、タブのドラッグ並べ替えは対象外とする。
- ブラウザのサイトデータ削除、利用モード、容量制限により保存データが失われる場合がある。
