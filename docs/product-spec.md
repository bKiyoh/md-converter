# Markdown変換エディタ プロダクト仕様

## 目的

Markdownで文章を作成し、SlackやBacklogなどの貼り付け先に適した形式へ変換・コピーできるWebアプリを提供する。

## MVP画面

PCでは左右2カラムとする。

- 左：Markdown入力
- 右：変換結果

画面幅が767px以下の場合は、入力と変換結果をタブで切り替える。初期表示は入力タブとし、変換しても自動では変換結果タブへ移動しない。

タブはクリックに加えて、左右矢印キーで隣のタブ、Homeキーで入力、Endキーで変換結果へ移動できるようにする。PCではタブを表示せず、入力と変換結果を同時に表示する。

## 主要機能

- Markdown入力
- 出力形式の選択
- リアルタイム変換
- 変換結果の表示
- クリップボードへのコピー
- 変換警告の表示
- LocalStorageへの自動保存
- ライト・ダークモード

## 出力形式

- Slack
- Backlog Markdown
- Backlog記法
- プレーンテキスト

## 画面項目

### 入力エリア

- Markdown入力欄
- 文字数
- 全削除

### 出力エリア

- 出力形式選択
- 変換結果
- コピーボタン
- 警告一覧
- 出力文字数

## 自動保存

- 入力内容をLocalStorageへ保存する
- ライト・ダークモードの選択をLocalStorageへ保存する
- 入力内容とテーマの変更後500ミリ秒程度のデバウンスを行う
- 再読み込み時に入力内容とテーマを復元する
- 保存済みのテーマがない場合はライトモードを使用する
- サーバーへ送信しない

## コピー

コピー成功時：

「Slack形式でコピーしました」

コピー失敗時：

「コピーに失敗しました。変換結果を選択して手動でコピーしてください。」

## MVP完了条件

- 主要Markdown要素を各形式へ変換できる
- 変換結果をコピーできる
- 再読み込み後に入力を復元できる
- 入力内容を外部へ送信しない
- 変換処理に単体テストがある
