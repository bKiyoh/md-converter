# Markdown変換エディタ プロダクト仕様

## 目的

Markdownで文章を作成し、SlackやBacklogなどの貼り付け先に適した形式へ変換・コピーできるWebアプリを提供する。

## MVP画面

PCでは左右2カラムとする。

- 左：Markdown入力
- 右：Markdownプレビューと変換結果を切り替えるタブ

画面幅が767px以下の場合は、入力と右ペインをタブで切り替える。初期表示は入力タブとし、変換しても自動では右ペインへ移動しない。

外側のタブはクリックに加えて、左右矢印キーで隣のタブ、Homeキーで入力、Endキーで右ペインへ移動できるようにする。PCでは外側のタブを表示せず、入力と右ペインを同時に表示する。

右ペイン内は「Markdownプレビュー」と「変換結果」のタブで同じ表示領域を切り替える。初期表示は変換結果とし、タブを切り替えてもMarkdown入力と選択中の出力形式を維持する。

## 主要機能

- Markdown入力
- 出力形式の選択
- リアルタイム変換
- Markdownプレビュー
- 変換結果の表示
- クリップボードへのコピー
- Markdownショートカット
- リスト入力の自動継続
- Tabキーによるリスト階層変更
- 変換警告の表示
- LocalStorageへの自動保存
- ライト・ダークモード

## 出力形式

- Slack
- Backlog Markdown
- Backlog記法
- プレーンテキスト

## 画面項目

### 入力エリア

- Markdown入力欄
- 文字数
- 全削除
- `Ctrl` または `Command` と `B`、`I`、`K` の組み合わせによる太字、斜体、リンクの挿入・解除
- Enterキーによる箇条書き・番号付きリスト入力の自動継続、および空項目での終了・階層移動
- リスト行または複数行選択時のTab・Shift+Tabによる2スペース単位のインデント変更
- IME変換中は独自のキー操作を実行しない

### 右ペイン

- Markdownプレビュー／変換結果タブ
- Markdownプレビューは既存のMarkdown解析結果から生成し、生HTMLは無効化する
- プレビュー用レンダラーは許可した要素だけを描画し、テキスト・属性・URLを安全に処理する
- 初期表示は変換結果タブ

### 変換結果タブ

- 出力形式選択
- 変換結果
- コピーボタン（変換結果が空の場合は無効）
- 警告一覧
- 出力文字数

## 自動保存

- 入力内容をLocalStorageへ保存する
- ライト・ダークモードの選択をLocalStorageへ保存する
- 入力内容とテーマの変更後500ミリ秒程度のデバウンスを行う
- 再読み込み時に入力内容とテーマを復元する
- 保存済みのテーマがない場合はライトモードを使用する
- サーバーへ送信しない

## コピー

コピー成功時：

「Slack形式でコピーしました」

コピー失敗時：

「コピーに失敗しました。変換結果を選択して手動でコピーしてください。」

成功・失敗の通知は一定時間後に消去する。コピーボタンはMarkdownプレビューには表示せず、Converterが返した変換結果の状態値をコピーする。

## MVP完了条件

- 主要Markdown要素を各形式へ変換できる
- 変換結果をコピーできる
- 再読み込み後に入力を復元できる
- 入力内容を外部へ送信しない
- 変換処理に単体テストがある
