# Markdown変換エディタ プロダクト仕様

## 目的

Markdownで文章を作成し、SlackやBacklogなどの貼り付け先に適した形式へ変換・コピーできるWebアプリを提供する。

## MVP画面

PCでは左右2カラムとする。

ヘッダーには「Markdown Converter」と情報アイコンを並べて表示する。情報アイコンを押すとモーダルを開き、タイトル「Markdown変換エディタ」と説明「貼り付け先に合わせて、ブラウザ内でリアルタイムに変換します。」を表示する。続けて、入力内容と設定は利用中のブラウザのLocalStorageに保存され、外部サーバーへ送信されないこと、およびブラウザのサイトデータを削除すると保存内容も削除されることを表示する。モーダル表示中は背面を操作できないようにし、閉じるボタン、Escapeキー、背景のクリックで閉じられるようにする。

- 左：Markdown入力
- 右：Markdownプレビューと変換結果を切り替えるタブ

画面幅が767px以下の場合は、入力と右ペインをタブで切り替える。初期表示は入力タブとし、変換しても自動では右ペインへ移動しない。

外側のタブはクリックに加えて、左右矢印キーで隣のタブ、Homeキーで入力、Endキーで右ペインへ移動できるようにする。PCでは外側のタブを表示せず、入力と右ペインを同時に表示する。

右ペイン内は「Markdownプレビュー」と「変換結果」のタブで同じ表示領域を切り替える。初期表示は変換結果とし、タブ内には「Preview / Markdownプレビュー」「Output / 変換結果」の重複する説明見出しを表示しない。タブを切り替えてもMarkdown入力と選択中の変換形式を維持する。

変換形式の選択とコピーボタンはヘッダーに配置し、PCと狭い画面のどちらでも右ペインの表示状態とは独立して操作できるようにする。

## 主要機能

- Markdown入力
- 変換形式の選択
- リアルタイム変換
- Markdownプレビュー
- 変換結果の表示
- クリップボードへのコピー
- Markdownショートカット
- リスト入力の自動継続
- Tabキーによるリスト階層変更
- 変換警告の表示
- LocalStorageへの自動保存
- ライト・ダークモード
- エディター内部スクロールの切り替え

## 変換形式

- Slack
- Backlog Markdown
- Backlog記法
- プレーンテキスト

## 画面項目

### 入力エリア

- Markdown入力欄
- 文字数
- `Ctrl` または `Command` と `B`、`I`、`E`、`K` の組み合わせによる太字、斜体、インラインコード、リンクの挿入・解除
- `Ctrl` または `Command` と `Shift + X`、`Shift + 7`、`Shift + 8`、`Shift + 9` の組み合わせによる取り消し線、番号付きリスト、箇条書き、引用の適用・解除
- `Ctrl + Alt + 1` または `Command + Option + 1` による見出し1の適用・解除
- 行加工は選択範囲と交差する行全体を対象とし、選択末尾が次行の先頭にある場合はその次行を含めない。対象の全非空行に同じ加工があれば解除し、それ以外は未加工行だけへ適用する
- 箇条書きは `- `、番号付きリストは選択範囲内の非空行を1から連番、引用は `> `、見出しはレベル1の `# ` を使用する。行頭の既存インデントは維持し、空行には記号を追加しない
- Enterキーによる箇条書き・番号付きリスト入力の自動継続、および空項目での終了・階層移動。項目の文章途中で改行した場合は、カーソルより後ろの文章を同じ階層の次のリスト項目へ移す
- リスト行または複数行選択時のTab・Shift+Tabによる2スペース単位のインデント変更
- IME変換中は独自のキー操作を実行しない

### 右ペイン

- Markdownプレビュー／変換結果タブ
- Markdownプレビューは既存のMarkdown解析結果から生成し、生HTMLは無効化する
- プレビュー用レンダラーは許可した要素だけを描画し、テキスト・属性・URLを安全に処理する
- 初期表示は変換結果タブ
- 変換結果タブには変換結果、警告件数、出力文字数を表示する
- 警告がある場合は出力文字数と同じ行に「警告 N件」ボタンを表示し、押下すると警告一覧を右ペイン内へ重ねて表示する
- 警告一覧は同じ警告文をまとめ、発生件数と取得できた位置情報を表示する
- 警告一覧の開閉によって左右ペインの高さを変えず、一覧が長い場合は一覧内をスクロールする
- 警告がない場合は警告ボタンと警告一覧の領域を表示しない

### ヘッダーの出力操作

- 情報アイコンの右隣に設定ボタンを配置し、ヘッダーへ独立したテーマ切り替えボタンは表示しない
- 変換形式選択とコピーはヘッダー右側へ横並びで配置する
- 「変換形式」ラベルとセレクトを横並びにする
- コピーは変換形式の右隣に置くアイコンボタンとし、変換結果が空の場合は無効にする
- コピー成功後はコピーアイコンを一時的にチェックアイコンへ切り替え、ツールチップを「コピーしました」とする。通知の消去時に元へ戻す

### 設定

- ヘッダー右側の歯車アイコンから、小型の設定ポップオーバーを開く
- ポップオーバーは設定ボタンの再押下、外側クリック、Escapeキーで閉じる
- テーマは既存の状態と切り替え・保存処理をそのまま利用し、設定内の月／太陽アイコンボタンでライト／ダークを切り替える
- エディター内部スクロールは初期状態をONとし、ONではエディターとMarkdownプレビューを画面内に収まる高さにして、それぞれの内部をスクロールする
- エディター内部スクロールがOFFの場合、内容に合わせてtextareaとMarkdownプレビューを伸縮し、内部の縦スクロールを表示しない
- 各設定は保存ボタンを設けず即時反映する

## 自動保存

- 入力内容をLocalStorageへ保存する
- ライト・ダークモードの選択をLocalStorageへ保存する
- 選択中の変換形式を `md-converter:output-format:v1` へ保存する
- 入力内容とテーマの変更後500ミリ秒程度のデバウンスを行う
- エディター内部スクロール設定を `md-converter:settings:v1` にJSONで保存する
- 変換形式は変更時に即時保存する
- 再読み込み時に入力内容、テーマ、変換形式を復元する
- 再読み込み時にエディター内部スクロール設定を復元し、不正なJSON・不正な値はONへフォールバックする
- 保存済みのテーマがない場合はライトモードを使用する
- 保存済みの変換形式がない場合または保存値が不正な場合はSlackを使用する
- サーバーへ送信しない

## テーマ切り替え

- 設定ポップオーバー内のアイコンボタンでライト・ダークモードを切り替える
- ライトモードでは月、ダークモードでは太陽のアイコンを表示し、切り替え先を `aria-label` と `title` で示す

## アイコンボタン

- 情報表示、設定、設定内のテーマ切り替え、コピーの各アイコンボタンは約40px四方の共通スタイルを使用する
- 各ボタンは操作を示す `aria-label` と `title` を持ち、キーボードフォーカスを視認できるようにする
- アイコンボタンは枠線を表示しない
- 通常時の背景は透明とし、hover時だけ背景色を付ける。disabled時は透明度を下げる

## コピー

コピー成功時：

「Slack形式でコピーしました」

コピー失敗時：

「コピーに失敗しました。変換結果を選択して手動でコピーしてください。」

成功・失敗の通知は、ヘッダーの操作と重ならず画面レイアウトへ影響しない固定配置のトーストとして右下に重ねて表示し、一定時間後に消去する。コピーボタンはConverterが返した変換結果の状態値をコピーする。

## MVP完了条件

- 主要Markdown要素を各形式へ変換できる
- 変換結果をコピーできる
- 再読み込み後に入力と選択中の変換形式を復元できる
- 入力内容を外部へ送信しない
- 変換処理に単体テストがある
