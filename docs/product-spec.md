# Markdown Converter プロダクト仕様

## 目的

Markdownで文章を作成し、SlackやBacklogなどの貼り付け先に適した形式へ変換・コピーできるWebアプリを提供する。

## MVP画面

PCでは左右2カラムとし、中央の区切りバーをドラッグして左右ペインの表示割合を変更できるようにする。初期値は50:50とし、各ペインの最小幅を確保する。区切りバーは左右矢印キーでも操作でき、Homeキーで左ペインを最小、Endキーで右ペインを最小、ダブルクリックで50:50へ戻せるようにする。

ヘッダーにはアプリ名を表すタイトルアイコンを表示し、独立した情報アイコンは表示しない。タイトルアイコンはライトモードで `title-icon-light.png`、ダークモードで `title-icon-dark.png` を使用し、代替テキストで「Markdown Converter」を保持する。タイトルアイコンを押すとモーダルを開き、タイトル「Markdown Converter」と説明「貼り付け先に合わせて、ブラウザ内でリアルタイムに変換します。」を表示する。続けて、入力内容と設定は利用中のブラウザのLocalStorageに保存され、外部サーバーへ送信されないこと、およびブラウザのサイトデータを削除すると保存内容も削除されることを表示する。モーダル表示中は背面を操作できないようにし、閉じるボタン、Escapeキー、背景のクリックで閉じられるようにする。ブラウザのfaviconには `favicon.png` を使用する。

- 左：Markdown入力
- 右：Markdownプレビューと変換結果を切り替えるタブ

画面幅が767px以下の場合は、入力と右ペインをタブで切り替える。初期表示は入力タブとし、変換しても自動では右ペインへ移動しない。

外側のタブはクリックに加えて、左右矢印キーで隣のタブ、Homeキーで入力、Endキーで右ペインへ移動できるようにする。PCでは外側のタブを表示せず、入力と右ペインを同時に表示する。

右ペイン内は「Markdownプレビュー」と「変換結果」のタブで同じ表示領域を切り替える。初期表示は変換結果とし、タブ内には「Preview / Markdownプレビュー」「Output / 変換結果」の重複する説明見出しを表示しない。タブを切り替えてもMarkdown入力と選択中の変換形式を維持する。

変換形式の選択とコピーボタンはヘッダーに配置し、PCと狭い画面のどちらでも右ペインの表示状態とは独立して操作できるようにする。

## 主要機能

- Markdown入力
- 変換形式の選択
- リアルタイム変換
- Markdownプレビュー
- 変換結果の表示
- クリップボードへのコピー
- Markdownショートカット
- リスト入力の自動継続
- Tabキーによるリスト階層変更
- 変換警告の表示
- LocalStorageへの自動保存
- ライト・ダークモード
- エディター内部スクロールの切り替え
- PC表示での左右ペイン幅の調整
- 最大7件のMarkdownタブの追加・切り替え・名前変更
- タブの削除、削除済みタブからの復元・完全削除
- 現在のMarkdown編集だけを表示するフォーカスモード
- 通常モードでの入力支援ガイド表示

## 変換形式

- Slack
- Backlog Markdown
- Backlog記法
- プレーンテキスト

## 画面項目

### 入力エリア

- 入力エリアの最上部に、ブラウザのタブを模したMarkdown文書タブを表示する
- アクティブな文書タブは入力面と連続して見える外観とし、「Input」「Markdown入力」の説明見出しは表示しない
- タブ追加の「＋」は現在の末尾タブの直後に表示する
- Markdown入力欄
- 入力欄のフッター左側にラベルのない入力支援のアイコンボタン、右側に文字数を表示する。アイコンボタンには操作内容を示す `aria-label` とツールチップを設定する
- 入力支援ボタンを押すと、フォーカスモードと同じ入力支援の解説をMarkdown入力欄の下、フッターの上に固定高のパネルとして表示する
- 入力支援パネルは入力欄に重ねず、内部を独立してスクロール可能にし、表示中もMarkdown入力欄を操作できるようにする
- 通常モードの入力支援はボタンの再押下またはEscapeキーで閉じ、入力欄のクリックでは閉じず、表示状態を保存しない
- `Ctrl` または `Command` と `B`、`I`、`E`、`K` の組み合わせによる太字、斜体、インラインコード、リンクの挿入・解除
- `Ctrl` または `Command` と `Shift + X`、`Shift + 7`、`Shift + 8`、`Shift + 9` の組み合わせによる取り消し線、番号付きリスト、箇条書き、引用の適用・解除
- `Ctrl + Alt + 1` または `Command + Option + 1` による見出し1の適用・解除
- 行加工は選択範囲と交差する行全体を対象とし、選択末尾が次行の先頭にある場合はその次行を含めない。対象の全非空行に同じ加工があれば解除し、それ以外は未加工行だけへ適用する
- 箇条書きは `- `、番号付きリストは選択範囲内の非空行を1から連番、引用は `> `、見出しはレベル1の `# ` を使用する。行頭の既存インデントは維持し、空行には記号を追加しない
- Enterキーによる箇条書き・番号付きリスト入力の自動継続、および空項目での終了・階層移動。項目の文章途中で改行した場合は、カーソルより後ろの文章を同じ階層の次のリスト項目へ移す
- リスト行または複数行選択時のTab・Shift+Tabによる2スペース単位のインデント変更
- IME変換中は独自のキー操作を実行しない

### 右ペイン

- Markdownプレビュー／変換結果タブ
- Markdownプレビューは既存のMarkdown解析結果から生成し、生HTMLは無効化する
- プレビュー用レンダラーは許可した要素だけを描画し、テキスト・属性・URLを安全に処理する
- 初期表示は変換結果タブ
- 変換結果タブには変換結果、警告件数、出力文字数を表示する
- 警告がある場合は出力文字数と同じ行に「警告 N件」ボタンを表示し、押下すると警告一覧を右ペイン内へ重ねて表示する
- 警告一覧は同じ警告文をまとめ、発生件数と取得できた位置情報を表示する
- 警告一覧の開閉によって左右ペインの高さを変えず、一覧が長い場合は一覧内をスクロールする
- 警告がない場合は警告ボタンと警告一覧の領域を表示しない

### ヘッダーの出力操作

- フォーカスモード切り替えボタンをヘッダー左端に配置し、その右隣にタイトルアイコンを表示する。独立した情報アイコンとテーマ切り替えボタンは表示しない
- 設定、変換形式選択、コピーはヘッダー右側へこの順で横並びに配置する
- 「変換形式」の文字ラベルは表示せず、テキストファイルから外向きの矢印を描いた変換先アイコンをセレクトボックス内の先頭に表示する。アイコンはホバーしても色を変更せず、セレクトボックス全体のホバーまたはキーボードフォーカス時に、他のアイコンボタンと同じ共通ツールチップで「変換先」と表示する。セレクトボックスのアクセシブルな名前も「変換先」とし、アイコンを押した場合もセレクトボックスを押した場合と同様に選択肢を開く
- 設定は変換形式の左隣に置く歯車アイコンボタンとする
- コピーは変換形式の右隣に置くアイコンボタンとし、変換結果が空の場合は無効にする
- コピー成功後はコピーアイコンを一時的にチェックアイコンへ切り替え、ツールチップを「コピーしました」とする。通知の消去時に元へ戻す

### フォーカスモード

- 通常ヘッダーの左端にフォーカスモード切り替えアイコン、その右隣にタイトルアイコンを表示する
- タブ名編集やポップオーバーなどがEscapeキーを処理していない場合、Escapeキーで通常モードとフォーカスモードを切り替える
- フォーカスモードではタイトルアイコンを含む通常ヘッダー、変換プレビュー、コピー、設定、タブ一覧、タブ追加・削除など、文章入力に直接関係しない機能を非表示にする
- PCでは左25%、中央50%、右25%の固定レイアウトとし、中央に選択中のタブ名とMarkdown入力欄だけを表示する
- 左領域には終了ボタン、解説ボタン、独立スクロール可能な入力支援の解説欄を配置する
- 767px以下では中央を全幅表示し、終了ボタンと解説ボタンを左上へ固定し、解説欄を左ドロワーで表示する
- タブ名は既存の名前変更仕様で編集でき、タブ名編集中のEscapeキーは名前変更だけをキャンセルする
- 通常の入力支援、保存、永続化を維持し、モード切り替え時にカーソル、選択範囲、textareaのスクロール位置、選択中タブを保持する
- フォーカスモード中はtextarea内部だけをスクロールさせる。保存済みのエディター内部スクロール設定は変更しない
- フォーカスモードと解説欄の開閉状態はLocalStorageへ保存せず、再読み込み時は通常モードで開始する
- 詳細は `docs/focus-mode-spec.md` に従う

### 設定

- ヘッダー右側の歯車アイコンから、小型の設定ポップオーバーを開く
- ポップオーバーは設定ボタンの再押下、外側クリック、Escapeキーで閉じる
- テーマは既存の状態と切り替え・保存処理をそのまま利用し、設定内の月／太陽アイコンボタンでライト／ダークを切り替える
- エディター内部スクロールは初期状態をONとし、ONではエディターとMarkdownプレビューを画面内に収まる高さにして、それぞれの内部をスクロールする
- エディター内部スクロールがOFFの場合、内容に合わせてtextareaとMarkdownプレビューを伸縮し、内部の縦スクロールを表示しない
- 各設定は保存ボタンを設けず即時反映する

## 自動保存

- Markdownタブの一覧、選択中のタブ、各タブの入力内容、削除済みタブをLocalStorageへ保存する
- タブ状態は版付きキー `markdown-editor-state-v1` に保存する
- 既存の単一文書キー `md-converter:draft:v1` だけが存在する場合は、内容を初期タブ「Untitled」へ移行する
- ライト・ダークモードの選択をLocalStorageへ保存する
- 選択中の変換形式を `md-converter:output-format:v1` へ保存する
- Markdown入力内容とテーマの変更後500ミリ秒程度のデバウンスを行う
- タブ追加、切り替え、名前変更、削除、復元、完全削除は操作直後に保存する
- エディター内部スクロール設定を `md-converter:settings:v1` にJSONで保存する
- PC表示の左右ペイン比率を `md-converter:settings:v1` にJSONで保存する
- 変換形式は変更時に即時保存する
- 再読み込み時にタブ一覧、各タブの入力内容、選択中のタブ、削除済みタブ、テーマ、変換形式を復元する
- 再読み込み時にエディター内部スクロール設定と左右ペイン比率を復元し、不正なJSON・不正な値はそれぞれONと50:50へフォールバックする
- 保存済みのテーマがない場合はライトモードを使用する
- 保存済みの変換形式がない場合または保存値が不正な場合はSlackを使用する
- サーバーへ送信しない

## Markdownタブ管理

- 初期状態では「Untitled」を1件作成し、タブは最大7件とする
- 各タブは一意のID、名称、Markdown入力、作成日時、更新日時を保持する
- タブ名は前後の空白を除いた1〜30文字とし、同名を許可する
- 最後の1タブは削除できない。削除確認と削除成功トーストは表示せず、復元は削除済みタブ一覧から行う
- 内容が空文字かつ名前がデフォルト形式の `Untitled` または `Untitled N`（Nは2以上）であるタブは、削除済み一覧へ残さず即時に完全削除する。変更前に保存された `文章N` も同じ扱いを維持する
- 削除済みタブは30日間保持し、一覧から復元または完全削除できる
- 削除済みタブ一覧は一覧外のクリックで閉じる
- タブ切り替え時は入力、Markdownプレビュー、変換結果、警告、コピー対象を選択中タブの内容へ切り替える
- 独自の編集履歴、複数ウィンドウ同期、競合解決は対象外とする
- 詳細は `docs/tab-management-spec.md` に従う

## テーマ切り替え

- 設定ポップオーバー内のアイコンボタンでライト・ダークモードを切り替える
- ライトモードでは月、ダークモードでは太陽のアイコンを表示し、切り替え先を `aria-label` と共通ツールチップで示す

## アイコンボタン

- タイトルアイコンによる情報表示、設定、設定内のテーマ切り替え、コピーの各アイコンボタンは約40px四方の共通スタイルを使用する
- 各ボタンは操作を示す `aria-label` と共通ツールチップを持ち、キーボードフォーカスを視認できるようにする
- アイコンボタンは枠線を表示しない
- 通常時の背景は透明とし、hover時だけ背景色を付ける。disabled時は透明度を下げる

## ツールチップ

- 操作名の補足に使用しているブラウザ標準の `title` ツールチップは、アプリ共通のツールチップへ置き換える
- 対象要素のホバーまたはキーボードフォーカス時に待ち時間なく表示し、ポインターが外れた場合、フォーカスが外れた場合、またはEscapeキーで非表示にする
- ツールチップは短いテキストだけを表示するシンプルな外観とし、操作可能な要素を含めない
- スクロール領域内や画面端の対象でも欠けないよう、表示位置をビューポート内へ調整する
- `aria-label` などのアクセシブルな名前は維持し、ツールチップだけを操作の説明手段にしない
- 二重表示を避けるため、共通ツールチップを設定した要素には `title` 属性を設定しない

## コピー

コピー成功時：

「Slack形式でコピーしました」

コピー失敗時：

「コピーに失敗しました。変換結果を選択して手動でコピーしてください。」

成功・失敗の通知は、ヘッダーの操作と重ならず画面レイアウトへ影響しない固定配置のトーストとして右下に重ねて表示し、一定時間後に消去する。コピーボタンはConverterが返した変換結果の状態値をコピーする。

## MVP完了条件

- 主要Markdown要素を各形式へ変換できる
- 変換結果をコピーできる
- 再読み込み後に入力と選択中の変換形式を復元できる
- 再読み込み後にタブ一覧、選択中のタブ、削除済みタブを復元できる
- 入力内容を外部へ送信しない
- 変換処理に単体テストがある
