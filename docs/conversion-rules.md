| ---------------- | ------------- | ------------- | ---------------- | -------------- | ---------------- |
| 見出し1          | `# 見出し`    | `*見出し*`    | `# 見出し`       | `* 見出し`     | `【見出し】`     |
| 太字             | `**重要**`    | `*重要*`      | `**重要**`       | `''重要''`     | `重要`           |
| 斜体             | `*補足*`      | `_補足_`      | `*補足*`         | `'''補足'''`   | `補足`           |
| 打ち消し線       | `~~廃止~~`    | `~廃止~`      | `~~廃止~~`       | `%%廃止%%`     | `廃止`           |
| リンク           | `[名称](URL)` | `[名称](URL)` | `[名称](URL)`    | `[[名称:URL]]` | `名称（URL）`    |
| 未完了タスク     | `- [ ] 対応`  | `☐ 対応`      | `- [ ] 対応`     | `- [ ] 対応`   | `□ 対応`         |
| 完了タスク       | `- [x] 対応`  | `☑ 対応`      | `- [x] 対応`     | `- [x] 対応`   | `■ 対応`         |

## Slackのテーブル

Markdownテーブルはコードブロック形式へ変換する。

入力：

```md
| 項目 | 内容         |
| ---- | ------------ |
| 事象 | 保存できない |
| 原因 | 空文字       |
```

## Slack変換の対象と補足

Slack変換は、Slack APIの `mrkdwn` ではなく、Slackのメッセージ入力欄で「マークアップでメッセージを書式設定する」を有効にした場合の記法を対象とする。したがって、リンクにはAPI向けの `<URL|名称>` ではなく、入力欄向けの `[名称](URL)` を使用する。

- 見出しは同等の記法がないため太字へ変換し、見出しレベルが失われる警告を返す。
- 箇条書きは `- `、番号付きリストは実際の番号と `. ` を使用する。ネストは2スペースのインデントで表す。
- チェックリストは未完了を `☐`、完了を `☑` で表し、操作可能なチェックボックスではなくなる警告を返す。
- コードブロックは3つのバッククォートで囲む。言語名またはメタ情報がある場合、それらはSlackのコードブロックでは保持できないため警告を返す。
- テーブルはパイプ区切りの内容をコードブロックへ変換し、表固有の配置やセル内装飾が失われる警告を返す。
- 水平線は `──────────` へ変換し、水平線としての構造が失われる警告を返す。
- ソフト改行と明示的な改行はいずれも改行文字として保持する。段落などブロック間は空行で区切る。
