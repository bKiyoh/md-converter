# リリース後変更記録

> 文書区分：初回リリース後に公開した変更の記録。予定や未完了の作業は記載しない。

## 記録方針

- 実装、必要な検証、公開が完了した変更だけを記録する
- 日付、公開バージョンまたはGitタグ、関連マイルストーン、利用者への影響を記載する
- 不具合修正、仕様変更、追加機能、依存・運用変更を区別する
- 詳細な判断経緯は `../archive/`、障害の原因と恒久対応は `../incident/` へ残す
- 公開日やバージョンが不明な場合は推測せず「未特定」と明記する

## 変更履歴

現時点で、このリポジトリから初回リリース後の公開済み変更は特定できていない。
`maintenance-plan.md` の項目は未完了の計画であり、この変更履歴にはまだ含めない。
